# STOCK – แยก Pickup List ตามลานลากตู้

สคริปต์ Python อ่านไฟล์ Excel (Pickup List / BKG) ในโฟลเดอร์ แล้วแยกข้อมูล
**ตามลานลากตู้** (คอลัมน์ `Pickup` / `Pickup Name`) ออกมาเป็นไฟล์ Excel คนละไฟล์ต่อ 1 ลาน

## แนวคิด

ดึงข้อมูลด้วยไลบรารีล้วน ๆ ไม่ใช้ AI ในขั้นตอนดึงข้อมูล

- อ่าน `.xls` ด้วย `pandas` + `xlrd`
- อ่าน `.xlsx` ด้วย `pandas` + `openpyxl`
- ถ้ามีไฟล์ `.pdf` ในโฟลเดอร์ ใช้ `pdfplumber` ดึงข้อความดิบออกมาเป็น `.txt`

ผลลัพธ์ที่ได้จัดรูปแบบให้อ่านง่ายแล้ว จากนั้นค่อยเอาไปวิเคราะห์ต่อ (โดยคนหรือ AI)

## ติดตั้ง

```bash
pip install pandas xlrd openpyxl pdfplumber
```

## วิธีใช้

```bash
# อ่านโฟลเดอร์ที่สคริปต์อยู่ -> เขียนผลลัพธ์ที่ ./output
python split_pickup_by_yard.py

# ระบุโฟลเดอร์ / โฟลเดอร์ผลลัพธ์เอง
python split_pickup_by_yard.py "D:\path\to\folder" -o "D:\path\to\output"
```

## ผลลัพธ์

| ไฟล์ | เนื้อหา |
|---|---|
| `<ชื่อไฟล์>__000_สรุปรวมทุกลาน.xlsx` | ตารางสรุปว่าแต่ละลานมีกี่งาน / กี่ตู้ |
| `<ชื่อไฟล์>__<รหัสลาน>_<ชื่อลาน>.xlsx` | 1 ไฟล์ต่อ 1 ลาน — ชีต **"รายการ"** (booking ทั้งหมด) + ชีต **"สรุป"** (นับงาน/ตู้ แยกตามบริษัทเจ้าของสินค้า) |

การจัดรูปแบบ: แช่หัวตาราง, ใส่ AutoFilter, ปรับความกว้างคอลัมน์, ตัดคำคอลัมน์หมายเหตุยาว,
แปลง `ETD` (`202609230130` → `2026-09-23 01:30`) และ `TRAN DT` (`20260918` → `2026-09-18`)

## หมายเหตุ

ไฟล์ข้อมูล (`*.xls`, `*.xlsx`, `*.pdf`) และโฟลเดอร์ `output/` ถูกใส่ไว้ใน `.gitignore`
เพราะเป็นข้อมูลลูกค้าจริง — ถ้าต้องการเก็บไฟล์ตัวอย่างลง repo ให้แก้ `.gitignore`
